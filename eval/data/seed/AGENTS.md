## For AI Agents

### Working In This Directory
- **The 313-row subset cannot verify the gold.** Measured: the constraints reference 764 distinct
  articles, and 474 of them (62%) are absent from the subset. The original README claimed 313 rows
  were "the test target" — that claim is wrong and is corrected in `README.md`. Always reach for the
  full dump when scoring constraints.
- **Never apply both SQL files.** The subset is a strict subset of the full dump; overlapping ids
  collide on the PK.
- `articles.id` is `GENERATED ALWAYS AS IDENTITY`, so the dumps use `OVERRIDING SYSTEM VALUE` to
  preserve original ids. That leaves `articles_id_seq` stale — the trailing `setval(...)` line fixes
  it to 4761. If you split or trim a dump, keep that line or run it manually, or the next real
  INSERT will collide.
- `public.articles` must be empty before applying (PK collision otherwise).
- `../../reset_test_db.py` deletes only `guid LIKE 'dummy-%'` articles, so rows seeded from here
  survive eval iteration loops. It also refuses non-localhost hosts without `--allow-remote`.
